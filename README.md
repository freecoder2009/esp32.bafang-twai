Application for pc to communicate with Bafang e-bike CAN controllers via json over serial and TWAI, using ESP32 board and TJA1050 transceiver.

Harware needed:
1. ESP32 board with usb connector
2. TJA1050 transceiver

Software dependencies:
1. ArduinoJSON (https://arduinojson.org/)

Based (codes, parameters, other values and constants) on other Bafang CAN projects:
1. Bafang Canable Pro (https://github.com/mdi-9/bafang_canable_pro/)
2. larssonwassen / bafang-can  (https://github.com/larssonwassen/bafang-can/)
